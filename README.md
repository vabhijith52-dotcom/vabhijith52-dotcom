### Featured Projects

#### 01. CloudRadar &bull; AI-Assisted Multi-Cloud FinOps & Infrastructure Optimization
> **AI-Powered Multi-Cloud Research Engine | Deterministic Cost Modeling**
>
> [`Repository`](https://github.com/vabhijith52-dotcom/Cloud-infra) &bull; **Stack:** `Python` &bull; `FastAPI` &bull; `React` &bull; `Next.js` &bull; `PostgreSQL` &bull; `Docker` &bull; `TinyFish Agents` &bull; `Pydantic`

- **Technical Description:** An autonomous cloud infrastructure cost and reliability platform that queries live AWS, Azure, and Google Cloud documentation and pricing pages using autonomous web agents, normalizes findings, checks compatibility using deterministic rules, and computes evidence-backed savings recommendations.
- **Key Engineering Contributions:**
  - **Deterministic Verification Engine:** Implemented strict architectural separation between probabilistic AI discovery (web research agents) and deterministic arithmetic (Python/Pydantic validation, rightsizing compatibility matching, and Decimal precision).
  - **Financial Precision:** Enforced fixed-point `NUMERIC/Decimal` arithmetic across all currency calculations to prevent floating-point rounding errors in multi-cloud billing aggregations.
  - **Immutable Audit Trail:** Structured an append-only evidence chain where every pricing observation preserves its source URL, retrieval timestamp, extraction method, run ID, and raw payload.
  - **Tiered Savings Model:** Formulated a 3-tier non-mixing savings model (*Estimated*, *Verified Potential*, and *Realized* delta from bill uploads) guaranteeing zero synthetic or unverified claims.

#### 02. Smart Dispatch Verification System &bull; Edge Computer Vision Logistics Pipeline
> **Automated Carton Counting & Vehicle Verification | Real-Time Edge Video Processing**
>
> [`Repository`](https://github.com/vabhijith52-dotcom/dispatch-system) &bull; **Stack:** `Python` &bull; `FastAPI` &bull; `Ultralytics YOLOv8` &bull; `ByteTrack` &bull; `PaddleOCR` &bull; `OpenCV` &bull; `PostgreSQL` &bull; `WebSockets` &bull; `TypeScript`

- **Technical Description:** An automated warehouse dispatch verification pipeline that tracks physical freight loading and verifies carrier credentials against enterprise logistics records using multi-camera video surveillance.
- **Key Engineering Contributions:**
  - **Spatial Object Tracking:** Implemented a centroid door-line crossing algorithm paired with ByteTrack multi-object tracking to eliminate double-counting of cartons under occlusions and variable human motion.
  - **Automated Vehicle Identification:** Integrated PaddleOCR with automated frame filtering and plate localization to detect, crop, and transcribe truck license plates upon loading bay docking.
  - **Sub-Second Event Delivery:** Built an asynchronous event pipeline utilizing WebSockets and PostgreSQL LISTEN/NOTIFY to broadcast verified counts and verification mismatches to operator dashboards with minimal latency.
  - **Browser-Safe Media Pipeline:** Integrated an automated FFmpeg H.264 transcoding pipeline resolving native OpenCV MP4 container playback limitations for browser streaming.

#### 03. KubeLab &bull; Interactive Client-Side Kubernetes Cluster Simulator
> **Zero-Backend Kubernetes Visualizer | Browser-Native Kubectl Terminal**
>
> [`Repository`](https://github.com/vabhijith52-dotcom/Kube-lab) &bull; **Stack:** `TypeScript` &bull; `Next.js` &bull; `React` &bull; `Tailwind CSS`

- **Technical Description:** An interactive, zero-backend, client-side Kubernetes simulator designed for hands-on distributed systems workshops and seminars, modeling cluster topologies and executing live commands in an embedded terminal emulator.
- **Key Engineering Contributions:**
  - **Pure Client-Side Engine:** Engineered a stateful Kubernetes simulation engine running entirely within an ~109 kB first-load bundle, eliminating backend cluster provisioning costs and infrastructure overhead.
  - **AST Command Parser:** Built a custom `kubectl` tokenizer and command parser supporting core verbs, flags, and switches (`get`, `describe`, `create`, `apply`, `rollout`, `exec`, `patch`, `label`, `expose`).
  - **Reactive Topology DAG:** Implemented a reactive state graph reflecting namespace isolation, pod lifecycle states, ConfigMap volume synchronization, and dynamic Service endpoint derivation.

#### 04. Smart OCR AI &bull; Computer Vision Document Intelligence Microservice
> **High-Accuracy Document Extraction | Containerized Preprocessing Pipeline**
>
> [`Repository`](https://github.com/vabhijith52-dotcom/smart-ocr) &bull; **Stack:** `Python` &bull; `Flask` &bull; `OpenCV` &bull; `Tesseract OCR` &bull; `PaddleOCR` &bull; `Docker`

- **Technical Description:** A containerized microservice engineered to extract structured text from degraded scans, mobile captures, and low-resolution physical documents through an adaptive computer vision preprocessing pipeline.
- **Key Engineering Contributions:**
  - **Multi-Stage Preprocessing Pipeline:** Engineered an adaptive image preparation pipeline (Gaussian noise filtering, Otsu dynamic thresholding, contour extraction, and morphological skew correction) significantly improving OCR character accuracy on low-contrast inputs.
  - **Containerized Architecture:** Packaged dependencies, native Tesseract binaries, and Python runtimes into a lightweight Docker container for reproducible cloud deployments.
  - **Stateless REST Interface:** Built a robust REST API handling multipart file ingestion, asynchronous processing, confidence scoring, and JSON structured payloads.
